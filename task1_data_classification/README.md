# Данные клиентских сервисов

## БД объектов недвижимости

### Открытая часть БД

Информация о расположении, описания, поэтажные планы, информация об актуальных ценах, предрассчитанные рекламные оценки:

- по условиям ипотечного кредитования на каждую квартиру  
- по ориентировочным ценам на аренду такой квартиры по данным ЦИАН.

Классификация данных: внутренние данные

* только из\-за того, что фронтэнд не обращается к ним напрямую ))

Риски:

- потеря данных:  
  - вероятность: низкая  
  - влияние: высокое (часть объектов не будут находиться в поиске, что препятствует продажам, причём это могут обнаружить случайно далеко не сразу);  
  - общая величина: средняя.  
- искажение данных (например, неоткрывающиеся картинки высокого разрешения в случае некорректной загрузки карточки квартиры)  
  - вероятность: средняя;  
  - влияние: среднее (такие вещи обнаруживаются быстрее);  
  - общая величина: средняя.  
- устаревание данных (например, когда проценты по ипотеке явно не соответствуют тому, что показано на сайте):  
  - вероятность: низкая  
  - влияние риска: низкое (если скрипт предрасчёта работает хоты бы раз в неделю, уже сгодится)  
  - общая величина: низкая.  
- недоступность данных из\-за DDoS-атаки:  
  - вероятность: средняя  
  - влияние: среднее  
  - общая величина: средняя.

### Закрытая часть БД

#### Неактивные карточки объектов недвижимости

Некоторые объекты недвижимости в этой базе застройщик может временно не выставлять в открытую продажу, чтобы не сбивать цены в районе и не терять эффекта “уникального предложения” для покупателей. Однако карточки объектов, скорее всего, готовятся сразу для всех квартир в доме, в т.ч. и для тех, которые сразу в продажу не увыставляются

Оценить, сколько квартир в доме распродано, можно через специальные сервисы (слава РосРеестру\!), но подробная информация, сколько у застройщика на самом деле нераспроданных объектов (и каких конкретно), составляет коммерческую тайну.   
Классификация: конфиденциальные данные.  
Риски: те же, что и для и для открытой части БД объектов недвижимости, а также:

- утечка данных (вероятность средняя, влияние среднее, общая величина средняя)

#### Данные о клиентской активности

Например, какие поисковые запросы он делал на сайте.

Персональные данные, т.е. ID клиента всяко может быть отслежен.

- если наши конкуренты будут знать, кто из посетителей смотрел  
- если риэлторские конторы будут знать, кто из посетителей искал у нас квартиру без ипотеки, они могут просто увести этих покупателей в сегмент вторичного жилья, и они будут для нас потеряны навсегда ; )  
- 

Классификация данных: конфиденциальные данные.

Риски:

- утечка данных  
  - вероятность средняя;  
  - влияние высокое:  
    - штраф до 5 млн рублей по 152-ФЗ;  
    - непрогнозируемая упущенная прибыль (10-100М);  
    - небольшой урон репутации;  
  - общая величина высокая.

Сюда же может относиться конкретная величина комиссии для риэлторов-посредников. Такая информация составляет коммерческую тайну.

# Данные BI

## БД BI

Аналитическая БД (Greenplum \+ S3). Скорее всего, сюда копируются данные из всех БД для их последующего анализа. Соответственно, там есть полный набор данных по сделкам с недвижимостью и вся информация о клиентах.

Риски:

- потеря данных:  
  - вероятность: низкая  
  - влияние: низкое  
    - скорее всего, данные легко восстановить из резервных копий \+ повторный экспорт из онлайн-БД за последнее время  
  - общая величина: низкая  
- искажение данных;  
  - вероятность: низкая;  
  - влияние: среднее   
    - т.к. будет обнаружено не сразу, и какое-то время BI будет вестись по некорректным данным, выдавая некорректные результаты;  
  - общая величина: средняя;  
- утечка данных:  
  - вероятность: средняя;  
  - влияние: критическое  
    - как для утечки БД сделок с недвижимостью;  
  - общая величина: критическая.

Классификация данных: строго конфиденциальные / секретные данные.
